# Lua for Roblox

> From zero to advanced Roblox game development.

Learn Lua and the Roblox engine step by step.
By the end you will be able to build any type of Roblox game.

---

## What This Track Is

This is the complete Lua and Roblox course.
It starts from absolute zero and goes to advanced game development.

No prior coding experience needed.
No long videos. Every lesson is short and focused.
Every stage ends with a real playable game.

---

## Who This Is For

- Complete beginners who have never coded
- Roblox players who want to make their own games
- Developers who want to understand advanced Roblox systems

---

## How to Use This Track

1. Start at Stage 1, Lesson 00
2. Do each lesson in order
3. Do the challenge before moving on
4. Do not skip lessons
5. Take your time

Every lesson folder has:

- README.md - the lesson
- code/ - reference files
- challenge.md - your exercise

---

## How to Learn Best

- Type every line of code yourself
- Do not copy and paste
- Break things on purpose
- Read the error messages
- Build small projects before big ones
- Ask questions when stuck
