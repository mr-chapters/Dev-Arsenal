# Challenge 01 - Basics

This is your exercise for Lesson 01.

Do not look at the solution until you have tried it yourself.
The point is to build the habit of solving problems on your own.

---

## The Goal

Write a script that prints information about you to the Output window.

The script must:

- Print a greeting
- Print your name
- Print your age
- Print the result of a math problem
- Include at least one comment

---

## Step by Step

1. Open Roblox Studio
2. Create a new Baseplate place if you do not have one open
3. In the Explorer, click ServerScriptService
4. Right-click it and choose Insert Object, then Script
5. Delete the default code inside the script
6. Write your own code
7. Press F5 to play
8. Check the Output window (press F9)
9. Fix any errors you see
10. Save your work

---

## Expected Output

When your script runs, the Output window should show something like:

```text
Hello, Roblox!
My name is Alex
I am 25 years old
10 times 5 equals 50
```

Your name and numbers will be different. That is fine.
The structure is what matters.

---

## Requirements

Your script must include:

- At least four `print` statements
- At least one print statement with a number
- At least one print statement with math (like `10 * 5`)
- At least one comment line
- No errors in the Output window

---

## Bonus Challenges

If you finish the basic challenge, try these.

### Bonus 1

Print five lines in a row, each one being a different fact about you.

### Bonus 2

Print a small picture made of text.

Example:

```lua
print("  *  ")
print(" *** ")
print("*****")
```

Run it. See what appears in Output.

### Bonus 3

Use a multi line comment at the top of your script to describe what the script does.

### Bonus 4

Break your script on purpose.
Remove a quote mark.
Run it.
Read the error in the Output window.
Then fix it.

Write down the error message in your own words.

---

## Hints

If you get stuck, these hints will help.

Hint for printing text:

```lua
print("your text here")
```

Hint for printing numbers:

```lua
print(42)
```

Hint for printing math:

```lua
print(10 * 5)
```

Hint for a comment:

```lua
-- this is a comment
```

Hint for multiple items on one line:

```lua
print("My age is", 25)
```

---

## Common Mistakes to Avoid

- Writing `Print` with a capital P. It must be lowercase.
- Forgetting the quotes around text.
- Forgetting the parentheses after `print`.
- Forgetting to press F5 to actually run the script.
- Forgetting to open the Output window to see the result.
