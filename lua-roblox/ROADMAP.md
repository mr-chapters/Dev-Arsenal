# ROADMAP

This is the full learning path for Roblox game development in this repo.

It is split into five stages. Each stage has its own folder and its own README.
Each stage builds on the one before it.

Do not skip stages. Each one unlocks the next.

---

## Stage 1 - Lua Basics

Location: `stage-1-lua-basics/`

Goal: Learn the Lua language itself.

By the end of this stage you can write Lua scripts without help.

Lessons:

- 00 - Setup
- 01 - Basics
- 02 - Variables
- 03 - Strings
- 04 - Math
- 05 - Conditionals
- 06 - Loops
- 07 - Functions
- 08 - Tables
- 09 - Metatables
- 10 - Modules
- 11 - Coroutines

What you build:

- Small scripts you run inside Roblox Studio
- Console output tests
- Mini logic puzzles

## Stage 2 - Roblox Systems

Location: `stage-2-roblox-systems/`

By the end of this stage you understand every major part of Roblox Studio.

- 06 - Inventory Systems
